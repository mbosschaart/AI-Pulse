# AI Pulse 0.1b

First public beta for macOS 14 and later, with Apple Silicon and Intel support.

- OpenAI API, ChatGPT Work/Codex, Claude, and Cursor usage cards.
- Saved card arrangements, compact view, provider visibility, and Shift-drag snapping.
- Liquid Glass styles, including transparent glass with white text.
- Independent movable Settings window with version and update controls.
- Signed in-place updates, checked only on the first Settings opening per app session or on demand.

Download AI-Pulse-macOS.zip and move AI Pulse.app to Applications. The app is Developer ID signed; this initial beta is not notarized. Provider dashboard integrations may change as providers update their services.

The next release will be used to validate the complete in-place upgrade from 0.1b.
