# AI Pulse 1.2

Connect accounts directly from your dashboard and see whether their usage readings are current.

- Click an unconfigured card or Compact entry to open that provider’s connection settings. Reconnect cards take you to the matching settings too. Dragging and refresh controls keep their existing behavior.
- New connection status LEDs: green for a successful current reading, amber for stale or failed checks, red when sign-in is required, and gray for unconnected or manually entered accounts. Freshness follows the selected refresh rate.
- A global **Connection status LEDs** switch in Settings controls all providers in Cards, Compact, the menu-bar overview, and desktop widgets. Enabled by default; your choice is saved.
- Provider Settings now shows the last-updated date and time, or Never. Failed checks retain the last successful update time. Timestamps stay off the cards.
- Updated documentation and refreshed screenshots for Cards, Compact, and Settings.

A green light reflects the last successful check, not continuous session monitoring. macOS controls desktop widget redraw timing.

## Install

Download **AI-Pulse-1.2.dmg** and drag AI Pulse to Applications, or use **AI-Pulse-macOS.zip**. Both contain the Developer ID signed, Apple-notarized app with a stapled ticket. SHA256SUMS.txt includes checksums.

Existing users can install through Settings → Check for updates. Connections and preferences are retained. Requires macOS 14 or later; native Liquid Glass requires macOS 26 or later.
